# BugsLife (バグズ・ライフ) - 超低消費・遠隔安否見守りシステム

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Android_6.0%2B-green.svg)](https://android.com)
[![Firebase](https://img.shields.io/badge/Firebase-Cloud_Firestore-orange.svg)](https://firebase.google.com/)

**BugsLife** は、一人暮らしの高齢者や遠方に住む家族を、プライバシーを守りながらバッテリー消費・通信量を極限まで抑えて見守るための **Android 向け相互安否見守りアプリケーション** です。

親世代への配慮として **「複雑な操作や画面操作を極限まで排除」** し、アプリを開かなくても裏で自動的に見守りが機能し続けます。

詳細なアーキテクチャ・データ構造・異常検知仕様については [詳細仕様書 (docs/SPECIFICATION.md)](docs/SPECIFICATION.md) をご覧ください。

---

## ✨ 主な特徴

- 🔋 **超低消費電力・超軽量通信**: 常時接続を行わず、1時間ごとの差分同期により月間わずか数MBの通信量。
- 🔕 **親に負担をかけない完全自動見守り**: 親御さんは普段通りスマホを使うだけ。画面ロック解除の履歴を自動で同期。
- 🔄 **端末再起動時の自動復旧**: スマホの充電切れや再起動後も、アプリを開き直すことなく裏で見守りを自動再開。
- 🚨 **2系統の異常検知**:
  - **人の異常**: 24時間スマホ操作がない場合、大音量アラームと通知で家族へ即座に通報。
  - **端末の異常**: 充電切れや故障・電波圏外による通信途絶を検知。
- 🔐 **安心の参加承認セキュリティ**: 合言葉を知っていても、既存メンバーの承認がないと参加・閲覧できない安全設計。

## 📱 かんたん初期設定ガイド

### 1. アプリの準備
1. [Firebase Console](https://console.firebase.google.com/) でプロジェクトを作成し、`google-services.json` を配置してビルド（または配布されたAPKをインストール）。
2. アプリを起動し、初期設定を行います。

### 2. 設定画面での入力
- **あなたのお名前**: 例「お母さん」「長男 太郎」
- **見守りグループ名（合言葉）**: 家族共通の任意の合言葉（例: `yamada-family`）

### 3. 参加の承認（初回のみ）
- 1人目がグループ名を設定すると自動的に登録完了となります。
- 2人目以降が同じグループ名を設定すると、1人目の画面に **「参加承認リクエスト」** が表示されます。**「承認」** をタップすると、お互いの見守りが開始されます。

## 💡 画面の見方と使い方

### ホーム画面
- **自分のステータス**: 「元気です 😄」「良くない 😣」をワンタップで送信可能（任意）。
- **相手のカード**:
  - 🟢 **通常時**: 最終確認時刻や、過去24時間の操作回数が一目でわかります。
  - 🚨 **緊急アラート**: 24時間スマホ操作がない場合、画面が赤く警告表示されアラーム音が鳴ります。
